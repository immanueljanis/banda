# Banda visual system

The supplied FE-PROMPT.md defines the design. Warm paper, warm ink, deep spice green, gold for commodities, and muted sage for yield. Manrope grotesk with Geist Mono for all figures. Headlines capped at 56px. One-pixel rules, squared certificates, no shadows. The hero certificate and account tree are the imagery. Motion is restricted to data and the once-only position consolidation. Dark mode uses separately defined readable surface and foreground tokens.
